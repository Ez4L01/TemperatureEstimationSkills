# 定子温度估计科研提示词库

本目录是普通 Markdown 文档资料库，用于保存、分类、查找和复制科研提示词；它不是 Agent Skill，也不需要安装。

## 使用方法

- 从[提示词索引](index.md)按研究用途查找条目。
- 阅读或复制提示词时，打开索引中链接的完整正文。查看、复制和整理提示词不会自动执行其中的任务，也不会启动模型训练。
- 只有在用户明确要求执行某条提示词时，才将其作为任务说明。
- 新增提示词时，将完整正文保存为 Markdown，保留原意和关键要求，并在 `index.md` 登记标题、用途、适用场景、可替换变量和正文链接；不得覆盖已有条目。
- 不创建没有提示词内容支撑的空目录；分类通过索引标题维护。确有多个同类提示词后，再按需要整理为子目录。

## 科研优化规范

原提示词中的完整模型优化规范与执行型 Skill 的科研执行规范内容完全一致，因此不在本目录重复保存。唯一正式正文位于 [`research-execution-spec.md`](../.agents/skills/stator-temp-optimizer/references/research-execution-spec.md)，请通过[索引](index.md)查看其分类和用途。
